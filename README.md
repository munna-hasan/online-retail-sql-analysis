# Online Retail SQL Analysis

SQL-based analysis of an online retail dataset using MySQL.

## Project Overview

This project analyzes online retail transaction data to find sales trends, customer behavior, product performance, and business insights.

## Tools Used

- MySQL
- SQL
- Data Cleaning
- Business Analytics

## SQL Analysis

Performed analysis on:

- Total revenue and sales
- Customer behavior
- Product performance
- Monthly sales trends
- Country-wise sales analysis
